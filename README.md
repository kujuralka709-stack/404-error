
# Custom 404 Error Page 🌐

## 📌 Project Description
This project is a custom 404 Error Page designed using HTML5 and CSS3.

It displays a friendly error message when a user visits a page that cannot be found. The page includes an attractive illustration, a large 404 heading, and a button to return to the homepage.

## 🎯 Objective
The main objective of this project is to practice:
- HTML page structure.
- CSS styling and layout design.
- Typography and color combinations.
- Flexbox alignment.
- Responsive web design.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## ✨ Features
- Attractive 404 error page.
- Friendly error message.
- Custom CSS illustration.
- Back to Homepage button.
- Clean and modern user interface.
- Responsive design for mobile and desktop.
- Hover effect on the button.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the index.html file.
4. Right-click and select Open with Live Server.
5. The Custom 404 Error Page will appear in your browser.
